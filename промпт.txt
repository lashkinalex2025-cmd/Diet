

Создай полностью готовое современное Web-приложение под названием **«Diet»** для определения пищевой ценности продуктов.

Приложение должно работать на компьютере, планшете и смартфоне, поддерживать PWA и иметь возможность установки на Android.

Главная функция приложения:

**Пользователь вводит название продукта в поле «Продукт», приложение через интернет обращается к базе данных продуктов, находит соответствующий продукт и показывает его КБЖУ.**

КБЖУ:

* Калории — ккал
* Белки — г
* Жиры — г
* Углеводы — г

Все значения по умолчанию показывать **на 100 г продукта**.

# 3. Поиск продукта через интернет

Приложение должно иметь реальный выход в интернет.

Не создавай фиктивный API и не используй исключительно локальный массив продуктов.

Используй внешний API базы пищевых продуктов.

Предусмотри адаптер API, чтобы источник данных можно было легко заменить.

Например, архитектура должна позволять подключить:

* USDA FoodData Central API
* Open Food Facts API
* другой совместимый API

Если выбранный API требует API Key, предусмотрите безопасную конфигурацию через переменные окружения.

**Никогда не размещай секретный API-ключ непосредственно в исходном коде GitHub.**

Создай:

`.env.example`

Например:

```text
VITE_FOOD_API_URL=
VITE_FOOD_API_KEY=
```

Если API позволяет работать без ключа — используй этот вариант.

# 4. Алгоритм поиска

После ввода продукта:

1. пользователь вводит название;
2. приложение проверяет корректность запроса;
3. отправляет запрос к API;
4. получает результаты;
5. выбирает наиболее подходящие продукты;
6. показывает список найденных вариантов;
7. пользователь выбирает нужный продукт;
8. приложение показывает подробную информацию о КБЖУ.

Не показывай случайный результат.

Если найдено несколько продуктов, покажи список:

**Найдено:**

* Куриная грудка, сырая
* Куриная грудка, приготовленная
* Куриное филе

Пользователь выбирает нужный вариант.
